1A. ADDITIONAL COST TO SCORE AGENDA
─────────────────────────────────────────────────────────────────────────────
Used by: azef_protocol (trash 1 other installed card)

The scoring pipeline in TurnManager._do_score_agenda() needs to check the
agenda card definition for `additional_cost_score` keys before allowing the
Corp to score.

Changes required:
• TurnManager._do_score_agenda():
  - Check agenda card_def for `additional_cost_score_trash_installed: true`.
  - If present: collect all Corp installed cards OTHER than the agenda being scored.
  - If no valid targets, block the score attempt.
  - Corp decision_maker chooses which of their installed cards to trash.
  - Trash that card (fire trash events), then proceed with scoring.
• Extend the AI score evaluation (CorpTurnAI) to factor in whether an
  additional trash cost is payable and worth it.

JSON key: `"additional_cost_score_trash_installed": true`

1B. BACKROOM MACHINATIONS: OPERATION AS AGENDA
─────────────────────────────────────────────────────────────────────────────
Used by: backroom_machinations

After being played (with tag-removal additional cost), this operation card
moves to the Corp's score area and counts as 1 agenda point. The card does
NOT go to Archives; it goes to score area.

Changes required:
• AbilityInterpreter: new effect type `add_played_operation_to_score_area`
  - Move the current operation card record from "in play"/"being resolved"
    into ctx.corp_score_area with agenda_points = 1.
  - Trigger corp_scores_agenda event (so things like Marrow fire).
  - Do NOT place it in Archives.
• TurnManager._do_play_corp_operation(): after effects resolve, check
  if the card has `adds_self_to_score_area: true`; if so, route it to
  score area instead of Archives.
• GameContext: corp_score increments by 1 (check win condition).

JSON keys: `"additional_cost_remove_runner_tag": true` (existing) and
  `"adds_self_to_score_area": true` on the operation definition.

─────────────────────────────────────────────────────────────────────────────

Effect: `trash_self_bypass_ice`.

• Big Deal: play when there is a card with 3+ adv counters and Corp has
  enough credits to win the game or score a 4/3. High priority play.

• Mitosis: play when Corp has 2 installable cards in HQ and wants to
  advance them in parallel. Evaluate potential score path.

• Mutually Assured Destruction: play when Runner is at low hand size and
  Corp can survive mass trash. Trash the lowest-value Corp cards.

• Extract: always gain 6cr; optionally trash a nearly-expired asset for 9cr.

• Moon Pool: activate when there are facedown agendas in Archives worth
  recovering, AND the Corp has low-value HQ cards to discard.

• Trust Operation: play when Runner has a key resource (Ghosttongue,
  Environmental Testing, The Twinning) and Corp has a useful Archives card.

• Stavka rez: always trash an expired/low-value card for the +5 str bonus
  if facing a strong icebreaker.

• Ob identity: prioritise trashing low-value rezzed cards to chain search
  each turn. Maintain a "wish list" of 1-less-rez-cost targets in R&D.

• Pravdivost: always place adv counter on the card closest to scoring
  threshold when Runner makes a successful run.

3C. SimRunnerAI / HumanDecisionMaker updates
─────────────────────────────────────────────────────────────────────────────

• choose_card_to_charge(): already implemented. Prioritize Endurance (for
  sub-breaking), Environmental Testing (towards 4-counter payout), The
  Twinning (for additional accesses).

• choose_deep_dive_access_card(): access agendas first; then cards with
  highest trash cost.

• choose_spend_click_for_deep_dive(): yes if any unaccessed agendas remain
  in the set-aside pile and runner has clicks.

• Captain Padma identity: charge Endurance or Environmental Testing on
  first R&D run each turn.

• Sable identity: plan runs to hit mark server first each turn. If mark is
  HQ or R&D, prioritize that run to gain the free [click].

• Esâ Afontov: almost always trigger on core damage. The card draw + sabotage 2
  is very strong. Exception: if grip is at max hand size, skip draw.

• Into the Depths: prioritize search_install_program if a key breaker is
  missing; otherwise gain 4cr per ice passed.

• Svyatogor Excavator: trash nearly-depleted counter cards (Revolver at 0
  counters, Propeller at 0, etc.) for 3cr each turn.

• The Twinning: plan a credit expenditure from an installed card each turn
  (spend from Cezve, Trickster Taka, etc.) to reliably accumulate counters.

• Backstitching: runner should plan to hit the mark server via backstitching
  whenever facing strong ice on that server.

• Ghosttongue: runner plays more events when Ghosttongue is installed. AI
  should increase event-play weighting by 1 per Ghosttongue installed.

• Light the Fire: evaluate whether the target remote server root cards are
  worth nuking. Strong play when Corp has a nearly-scored agenda with an
  upgrade like Ash or Warroid Tracker.

• Begemot: strength grows with core damage taken. AI should factor Begemot's
  current strength into ice-breaking decisions.

Runner identities in Midnight Sun: Esâ Afontov (Anarch), Nyusha "Sable"
Sintashta (Criminal), Captain Padma Isbister (Shaper). The campaign should
unlock these three identities across its arc (one per two acts roughly),
with the other Runner cards unlocking progressively.

The Runner plays through 6 Corp decks, each themed around Midnight Sun
mechanics. Cards available: Midnight Sun + Parhelion + TAI + RWR + Elevation
+ Vantage Point + System Gateway (Standard ban list applies).

NOTES ON SUBTYPES AND KEYWORDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HARMONIC: Already introduced in Parhelion (Pulse, Bloop). Midnight Sun adds
  Wave and Echo as additional harmonic ice. The count_rezzed_harmonic_ice()
  method already exists. No new engine handling needed for the subtype itself.

BIOROID: Already a subtype for HB ice (e.g., Hákarl). Trieste Model Bioroids
  references bioroids by subtype. The has_subtype("bioroid") check must work
  for Hákarl 1.0 and any other bioroid ice the Corp uses.

MARK: Already introduced in Parhelion (info_bounty, tunnel_vision). Midnight Sun
  adds Backstitching, Carpe Diem, Nyusha Sable (identity), and Virtuoso.
  No new engine work for mark itself — just new cards using existing mechanism.

CHARGE: Already introduced in Parhelion (orca, flux_capacitor). Midnight Sun
  adds Daeg, Stoneship Chart Room, Rigging Up, Captain Padma. All use the
  existing charge_card effect. No engine changes needed.

REGION: Vladisibirsk City Grid is a region upgrade (limit 1 per server).
  The region restriction already exists in the engine.

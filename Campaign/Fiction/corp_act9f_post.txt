STREET GALLERY: CLOSED
by Desh Fuentes-Calloway

The Lilypad Gamble creates evidence by design. Not incidentally — the deck's tools include archival functions that record access events in a format intended for public presentation. When Arissana runs a server, the Lilypad Gamble is simultaneously creating a document. A successful run produces a document that can be exhibited. An unsuccessful run produces a document of an attempt.

The Syndicate understood this before the engagement began and structured the defensive response around it: if every run produces a document regardless of outcome, the goal is to ensure the documents show nothing interesting.

An attempt against impenetrable ICE is not an interesting exhibit.

The narrative control server was triple-layered. Arissana ran it twice. Both times produced documents showing a runner being stopped at the outer ICE, with no access to anything that could constitute narrative control evidence. The documents, if exhibited, would show the Syndicate's ICE working as intended. The monitoring team flagged this as, possibly, an acceptable exhibition.

Arissana scored three points through servers that had been deliberately left accessible at the outer layer — exposing agendas in locations where the access would produce low-value evidence, drawing the Lilypad Gamble toward targets that yielded artifacts of minimal usefulness to the coalition's public exposure objectives.

Seven to three. Narrative control infrastructure intact.

The gallery does not open tonight. There is nothing to exhibit.

The gamble found walls that made for dull photographs.
The narrative control server produced no useful exhibits.
Closed. Dark. The story the Syndicate tells is still the Syndicate's.
